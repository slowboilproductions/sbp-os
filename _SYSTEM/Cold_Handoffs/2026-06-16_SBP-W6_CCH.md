## Gotchas / lessons
- **W5 cautionary tale:** the W5 session misread its relay and only re-ran an audit — NO new work. A Build relay means BUILD; the audit is ONE pass at the very end, not the opening move.
- **Doer is preview-blind** (no in-container browser) — motion/visuals get verified by the operator on Vercel; build clean, expect a tuning pass.
- **Card glow:** use `isolation: isolate` + `z-index:-1` ::before (NOT `.card > * { z-index:1 }`, which overrides absolutely-positioned children like `.sg__live`).
- **`.prose a` out-specifies `.btn`** → buttons inside prose go invisible; `.prose a.btn` rules fix it (pre-existing).
- Operator is **web + mobile only**; asset hand-off is GitHub web upload or the swap slots. No secrets in source (Contact handler stays Step-3). **No popups — propose in plain chat (B-6).**
- Each signature uses a single `querySelector` — fine for one-per-page; if a component is ever placed twice on a page, generalize to `querySelectorAll`.
