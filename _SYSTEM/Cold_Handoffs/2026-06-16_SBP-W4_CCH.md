## Gotchas / lessons
- **Doer is preview-blind** (no in-container browser) — motion/visuals get verified by the operator on Vercel; build clean, expect a tuning pass. (cairosvg/Pillow let me eyeball *static* renders via Read — used it to vet the banner bend + bottle frames.)
- **Sticky pin gotcha:** the tall scroll length must sit on the sticky element's **direct parent**, not an outer wrapper (cost a round on the tour).
- **`.prose a` out-specifies `.btn`** → buttons inside prose go invisible (rust-on-rust); `.prose a.btn` rules fix it.
- Operator is **web + mobile only**; asset hand-off is GitHub web upload or the swap-slots above. No secrets in source (Contact handler stays Step-3).
- Operator dislikes scroll-jacking that needs many scrolls per step — prefer continuous scrubs or tab/click controls.
